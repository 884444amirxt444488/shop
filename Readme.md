# 🛒 Full-Stack Shop

A full-stack e-commerce application built with React, TypeScript, Node.js, Express, and PostgreSQL.

## Features

- User Authentication
- JWT Access & Refresh Tokens
- Product Management
- Shopping Cart
- Payment Flow
- Stock Management
- PostgreSQL Transactions
- React Query Optimistic Updates
- Loading & Error Handling

## Tech Stack

### Frontend
- React
- TypeScript
- React Query
- Axios
- React Router

### Backend
- Node.js
- Express
- PostgreSQL
- JWT
- bcrypt
